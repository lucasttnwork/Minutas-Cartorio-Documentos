## 🎨 Design System do Projeto

### Paleta "Platinum & Onyx" (Já Configurada)

**Light Theme - "Ivory Platinum":**
```css
--background: oklch(98% 0.004 55);           /* Warm ivory */
--primary: oklch(30% 0.018 250);             /* Deep Slate */
--accent-vivid: oklch(70% 0.090 48);         /* Champagne Gold */
--teal-deep: oklch(45% 0.10 180);            /* Deep Teal */
```

**Dark Theme - "Onyx":**
```css
--background-dark: oklch(10% 0.010 250);     /* Deep onyx */
--primary-dark: oklch(80% 0.010 250);        /* Silver luminoso */
--accent-dark: oklch(75% 0.085 48);          /* Gold brilhante */
```

**Fontes:**
- Geist (sans-serif) - Principal
- Geist Mono (monospace) - Código

**Filosofia**: Sofisticação notarial, sem azul/violeta típico de IA.
