🚀 3 MINUTOS - ESSENCIAL:

A arquitetura segue este padrão:

   REQUEST
      ↓
   [CORS check] ← Sempre!
      ↓
   [Validate input]
      ↓
   [Start logging]
      ↓
   [Fetch from DB]
      ↓
   [Download file] ← Use service client
      ↓
   [Normalize DOCX?] ← normalizeFilesForGemini()
      ↓
   [Convert to Base64] ← arrayBufferToBase64()
      ↓
   [Call Gemini API] ← callGemini()
      ↓
   [Parse JSON] ← parseGeminiJson() - robusta!
      ↓
   [Update DB]
      ↓
   [Log success] ← com tokens!
      ↓
   [Return response]
      ↓ [ERROR]
   [Log error]

      └─ DocumentType, ClassificationResult, etc

🔑 CONCEITOS-CHAVE:

   SERVICE CLIENT:    createServiceClient()  = Bypass RLS (use para admin)
   ANON CLIENT:       createSupabaseClient()  = Respeita RLS

   FILE NORMALIZE:    normalizeFilesForGemini()  = DOCX → HTML
   BASE64 CONVERT:    arrayBufferToBase64()      = Arquivo → String

   GEMINI CALL:       callGemini(prompt, base64, mimeType)
   PARSE RESULT:      parseGeminiJson<T>(text)  = Robusta contra erro

   LOGGING:           startExecution() → logSuccess()/logError()
   TOKENS TRACKED:    inputTokens, outputTokens, cost_estimate

   DYNAMIC PROMPTS:   loadExtractionPrompt(tipo) = Do banco!
